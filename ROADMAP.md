# Roadmap

Fiestaaa is maintained as a focused private-event planning application. The
public repository accepts contributions that improve the official app,
developer experience, reliability, accessibility, documentation, and test
coverage.

## Good Fits

- Event, invitation, carpool, item-list, poll, shared-expense, QR, and profile
  improvements that match the current product direction.
- Accessibility, responsive layout, localization, and UI consistency fixes.
- Tests, CI hardening, dependency maintenance, and public documentation.
- Small refactors that reduce complexity without changing product behavior.

## Discuss First

- New third-party integrations.
- Large navigation or information-architecture changes.
- Changes to authentication, account deletion, privacy-sensitive data, or
  notification behavior.
- Features that require backend API changes or production operations work.

## Out of Scope

- Official support for unrelated self-hosted deployments.
- Publishing independently branded app-store builds from this repository.
- Production signing, deployment, backup, incident-response, and observability
  runbooks.
- Changes that reuse Fiestaaa branding for public forks or derived services.

## Maintainer Notes

Release timing, versioning, mobile signing, production deployment, and final
scope decisions remain maintainer responsibilities.
