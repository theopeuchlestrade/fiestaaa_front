# Brand and Asset Policy

This repository's source code is licensed under `MPL-2.0`. That license applies
to the covered source code. It does not grant a general right to use the
Fiestaaa name, logos, app icons, domain names, screenshots, product copy, or
other brand assets.

This policy is intended to make the project easier to fork and contribute to
without creating confusion about what is official.

## Project Brand Assets

Fiestaaa brand assets include, without limitation:

- the Fiestaaa name and visual identity;
- app icons and launcher icons in `web/`, `android/`, `ios/`, `macos/`, and
  `windows/`;
- product screenshots, store assets, and marketing copy if added later;
- domain names and public service names associated with the official project.

## Allowed Use

You may use the Fiestaaa name and repository references to:

- describe this project accurately;
- link to the original repository;
- say that a project is a fork of, derived from, or compatible with Fiestaaa;
- include screenshots or logs when reporting bugs, submitting pull requests, or
  documenting development work.

These uses must not imply endorsement, sponsorship, or official status unless
that has been explicitly agreed.

## Restricted Use

Without explicit permission, do not:

- use the Fiestaaa name, logo, app icon, or visual identity as the primary
  branding for a public fork, hosted service, package, app store listing, or
  commercial offering;
- register confusingly similar domains, social accounts, package names, bundle
  identifiers, or application identifiers;
- present a modified version as the official Fiestaaa app;
- use Fiestaaa brand assets in a way that suggests endorsement or partnership.

## Forks and App Builds

Public forks and independently distributed builds should use their own name,
icons, logos, visual identity, domains, package names, bundle identifiers, and
application identifiers. It is fine to state factually that the project is based
on Fiestaaa, as long as users can clearly tell it is not the official project.

## Third-Party Logos

Third-party names, logos, and service marks remain the property of their
respective owners.

The logos in `assets/logos/` are included to identify integration providers in
the app UI. They are not licensed by this repository for unrelated reuse, and
their use must comply with the relevant third-party brand guidelines.

## Questions

For permission requests or unclear cases, contact the maintainer through the
project's normal private channel.
