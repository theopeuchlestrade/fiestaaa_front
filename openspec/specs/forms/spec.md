# Forms

## Purpose
Define the accepted presentation contract for Fiestaaa.

## Requirements

### Requirement: Shared forms and safety
Create and edit SHALL share section ordering, validation, essential fields before advanced options, one save action, draft protection and exit guards. Authentication, reset and profile fields SHALL use shared styles and translated feedback.

#### Scenario: Unsaved creation
- **WHEN** a creator leaves with unsaved fields
- **THEN** the existing leave confirmation and account-scoped draft behavior remain available
